# 검증 범위

[프로젝트 소개로 돌아가기](../README.md)

이 문서는 **2026-10-08 원본 프로젝트 검증 기록**과 **2026-10-13 공개용 캡처 환경 검증**을 구분해 정리합니다. 공개 저장소에 실행 가능한 원본 코드나 원본 증적을 포함하지 않으므로 여기에서 같은 검사를 바로 재실행할 수 있는 구성은 아닙니다.

## 공개용 화면 촬영 · 2026-10-13

[화면 설명과 캡처 7장](walkthrough.md) · [자동 검사 요약 JSON](../assets/capture-verification.json)

| 구분 | 확인한 내용 |
|---|---|
| 소스 기반 화면 | 로컬 React UI 사본 빌드, 로컬 공유 결과 렌더러 실행 |
| 데이터 | 별도 작성한 가상 제품·이슈·TC·실행 기록과 샘플 알림 6건 |
| 샘플 자동 검사 | 전체 6건 → 경고 2건 및 심각도 일치 → 전체 6건 복구 |
| UI 자동 검사 | TC·결과·공유 화면 표시, 증적 전환·확대·닫기, 오류·재시도 |
| 검사 관찰 | 해당 자동 검사에서 페이지 오류 0건, 외부 요청 0건, 데이터 변경 요청 0건 |
| Computer Use | TC에서 실행 이력으로 이동, 증적 선택·확대·닫기, 공유 테마 전환, 본문 재시도와 캡처 |

7장은 화면 자료의 수이며 제품 TC 통과 수가 아닙니다. 실행 결과 API는 가상 응답이고 DB 저장·실제 제품 실행·사람 검수·외부 댓글 게시를 수행하지 않았습니다. 캡처의 실행 시각·ID·작성 단계도 예시 값입니다. 원본 프로젝트 검증 내역은 아래에 별도로 기록합니다.

## 공유 결과 화면

| 검증 항목 | 범위 |
|---|---|
| 렌더링·출력 검사 | 3건: 출력 이스케이프·읽기 전용 구성, 게시 범위 이미지 경로, 허용 스크립트 해시 |
| 화면 크기 | 1920×1080, 1536×864, 1366×768, 1280×720 |
| 테마 | 라이트·다크 |
| 상호작용 | 썸네일·이전/다음, 이미지 원본 크기, 확대 창 열기·닫기, 포커스 복귀 |
| 이미지 데이터 | 실제 공유 사례의 한 장과 별도 두 장 fixture를 구분 |

브라우저에서 페이지 오류 없이 동작한 것을 확인했습니다. 모바일 사용성과 모든 접근성 항목을 검증했다고 주장하지 않습니다.

## 이슈 상세·런 이동

- 두 제품에 대해 이슈에서 런 결과로 이동하고 원래 이슈로 돌아오는 흐름 확인.
- 새로고침과 별도 페이지 진입 시 복귀 경로 확인.
- 본문 조회 실패 안내, 분석 버튼 제한, 재시도 버튼 활성화와 성공 후 본문 표시 확인.
- mocked UI 캡처 24개 기록.
- 해당 검사 중 외부 변경 요청 0건, 페이지 오류 0건 기록.

이 숫자는 제품 테스트케이스 통과 수나 업무 효율 개선 수치가 아닙니다.

## 연결·정적 검사

| 대상 | 방법 |
|---|---|
| 외부 조회 | 가짜 전송으로 경로·식별자·권한 범위·구버전 호환 확인 |
| 댓글 게시 | 가짜 전송·DB 호출을 사용한 회귀 검사 |
| 웹 코드 | 폴더 의존 방향 검사, TypeScript 검사, Vite 빌드 |
| QA 패키지 | 필수 파일 경로·연결 검사, 증적 생성 규격 검사 |

mocked UI와 정적 검사는 실제 제품 데이터의 정확성이나 모든 실행 환경의 정상 동작을 보증하지 않습니다. 실제 제품 검증은 메뉴별 실행 결과와 증적 검수의 별도 근거가 필요합니다.

## 수치 성과를 기록하는 기준

시간 절감·성공률·결함 발견률을 제시하려면 비교 대상, 표본 수, 기간, 환경과 측정 방법을 먼저 정해야 합니다. 이 저장소에는 측정하지 않은 개선률을 넣지 않았습니다.
